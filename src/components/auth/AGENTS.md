- Member content access is decided server-side by public.member_content_allowed() (RLS on course tables) and has_member_access(); ProtectedRoute only mirrors my_member_access() via src/lib/memberAccessGate.ts — signing up/in never grants access and hiding pages is never the only guard.
- Accounts are created only by the member-signup edge function after a server-side purchase/grant match on the checkout email, or by member-checkout-signup from a paid live Stripe Checkout Session id (re-fetched from Stripe; one session binds to one new account atomically via member_checkout_claims; login email may differ and is never payment evidence; consumed payments never qualify another account) (public sign-up is disabled in auth settings; confirmation uses the standard signup email via resend); paid edge functions call _shared/memberGate.ts — signup UI is never the only guard.
- Course files are a private bucket; rows keep a stable public-style URL as an identifier and the UI swaps it for 1-hour signed links via src/lib/courseFiles.ts (never store signed links).
